ClipMaker

Windows-sovellus, joka leikkaa kappaleesta parhaan 20–60 sekunnin kohdan, yhdistää siihen kansikuvan tai videon ja valmistaa pystyclipin YouTube Shortsia ja TikTokia varten.

Tietosuojaseloste Käyttöehdot

Mitä ClipMaker tekee

  • Etsii musiikista energisimman kohdan automaattisesti
  • Luo 9:16-videon kuvasta tai videosta
  • Tukee esikuuntelua ennen tallennusta
  • Voi julkaista YouTube Shortsiin tai lähettää TikTok-inboxiin, kun tili on yhdistetty

Kehittäjäintegraatiot

  • YouTube Data API v3 (OAuth, käyttäjän oma kanava)
  • TikTok Login Kit + Content Posting API (OAuth, käyttäjän oma tili)
  • Sovellus toimii paikallisesti Windowsissa; julkaisu tapahtuu vain käyttäjän pyynnöstä
