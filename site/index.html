ClipMaker

A Windows desktop product for musicians and creators. ClipMaker finds the strongest 20–60 second section of a track, combines it with cover art or video, and prepares a vertical clip for YouTube Shorts and TikTok. Publishing uses the creator’s own Google/YouTube or TikTok account — ClipMaker never posts without an explicit click.

How ClipMaker works

End-to-end flow on the user’s Windows PC. Media stays local until the user chooses to publish.

  1. Import audio + visual Drop a song (WAV/MP3) and cover image or background video into the desktop app.
  2. Find the best moment ClipMaker analyzes loudness/energy and suggests a 20–60 second start point. The user can preview and adjust.
  3. Render a vertical clip Export a 9:16 MP4 suitable for Shorts and TikTok, saved on the user’s machine.
  4. Connect accounts (optional) OAuth login for YouTube and/or TikTok. Tokens are stored only in the user’s local AppData folder.
  5. Publish on demand One click uploads the clip to YouTube Shorts and/or TikTok (direct post or creator inbox), with an AI-content label when enabled.

Product features

Local-first desktop app

  • Runs on Windows; no ClipMaker cloud account required
  • Drag-and-drop audio and cover art
  • Auto best-moment detection + manual start time
  • Presets for TikTok / YouTube / square

Creator publishing

  • YouTube Data API v3 — Shorts upload to the user’s channel
  • TikTok Login Kit (Desktop) — user authorization
  • TikTok Content Posting API — inbox draft or direct post
  • Optional synthetic-media / AIGC labels

TikTok integration

ClipMaker uses TikTok for Developers products to let the signed-in creator authorize ClipMaker and upload a short video they just rendered. Products and scopes used:

Login Kit (Desktop)

user.info.basic

Opens the TikTok authorization page in the browser. After the user approves, ClipMaker receives an OAuth code on http://127.0.0.1:8765/callback/ and stores tokens locally so the same creator can publish later without logging in every time.

Content Posting API

video.upload · video.publish

video.upload sends the rendered MP4 to the creator’s TikTok inbox as a draft. video.publish posts directly with caption (Sandbox: private / SELF_ONLY until the app is approved). The user chooses the mode in the ClipMaker UI and must click Publish.

FAQ

Does ClipMaker post without permission?

No. Connecting TikTok/YouTube only stores OAuth tokens. Uploads happen only when the user presses Publish.

Where is data stored?

Media files stay on the user’s PC. OAuth tokens live under the user’s local AppData\ClipMaker folder. See the Privacy Policy.

Is this a mobile app?

No. ClipMaker is a Windows desktop app using TikTok Login Kit for Desktop and the Content Posting API.
